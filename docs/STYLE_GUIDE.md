# Разбор референса и формулы стиля

Референс: `@drleonkessel`, ролик про эго, 25 сек, 1080×1920 @ 60 fps, **4.2M просмотров / 745K лайков / 97K сохранений**.
Подпись: *«Parfois, ton orgueil est le meilleur des carburants. À toi d'en faire une force, pas une faiblesse.»*
(«Иногда гордость — лучшее топливо. Сделай её силой, а не слабостью.») Хэштеги: `#ego #motivation #mindset #discipline #fyp`.
Звук: `original sound - TN MUSIC` (кинематографичный бит ~103 BPM).

## 1. Сюжет (покадрово)

| Время | Что происходит | Зачем это работает |
|---|---|---|
| 0–8 с | Тёмный класс. Три стикмена за партами: **DISCIPLINE**, **EGO**, **TALENT** (спит, «Zzz»). Учитель проходит на переднем плане и раздаёт листы. Оценки над головами: A, A−, **C у Эго**. Эго хватается за голову. | Ярлыки сразу объясняют идею без слов. Каждый узнаёт себя в одном из трёх. |
| 8.6–10 с | Крупный план Эго с листом «C» над головой, наезд камеры. | Эмоция: унижение, задетая гордость. |
| 10–14 с | Ночь. Эго за столом при лампе, в окне синяя ночь. Пишет. | Начало «грайнда». |
| 14–16.5 с | Эго у доски, решает уравнения. | Показ процесса, а не результата. |
| 16.5–21 с | Тайм-лапс: окно из ночи в рассвет, часы, стопка книг растёт. | Время = цена результата. |
| 21–25 с | Снова класс. DISCIPLINE — A, TALENT — A− (всё ещё спит), **EGO — A+**, поднимает руки. | Развязка + мораль: гордость как топливо. |

## 2. Визуальные правила

- **Персонажи:** белые матовые «пилюльные» стикмены — круглая голова, торс-капсула, толстые конечности с круглыми концами, лёгкое свечение. Лица нет вообще.
- **Ярлык над головой:** моноширинный шрифт, капс, большой трекинг (`D I S C I P L I N E`), маленький размер. Это главный носитель смысла.
- **Проп-индикатор:** белый лист с красной обведённой оценкой парит над ярлыком.
- **Палитра:** почти монохром, угольно-серый (#16171a … #24252a). Цвет даёт только свет: синие окна ночью, тёплая лампа (#ffc978), рассвет (#f2a65a), красная печать.
- **Глубина:** сильный боке. Задние ряды и передний план размыты, резкость на главном ряду. Размытые фигуры на переднем плане (учитель) — ощущение «реальной камеры».
- **Камера:** медленные наезды и дрейф, без резких движений. Склейки строго на бит.
- **Текст на экране:** почти нет. Смысл — через ярлыки и подпись к посту.
- **Длина:** 18–25 сек, 6–8 планов.

## 3. Формула ролика (то, что движок повторяет)

1. **Архетипы-ярлыки** (2–3 качества как персонажи).
2. **Измеримый результат** (оценка, бой, уровень), где герой проигрывает.
3. **Эмоциональный крупный план.**
4. **Монтаж работы** (ночь → рассвет, часы, книги, доска).
5. **Реванш** — тот же измеритель, но герой побеждает.
6. **Мораль** — одной фразой в подписи или на финальной карточке.

## 4. Звук

- 95–110 BPM, тёмный кинематографичный трэп / slowed phonk / montagem с выраженным **дропом**.
- Склейки на долю, **кульминация ровно на дропе** (движок выравнивает это сам).
- В нише сейчас (радар по `@drleonkessel`, 02.11.2026): *Nightcrawler*, *ZOOMTEKK*, *NEMESIS*, *MONTAGEM GAME*, *Paper Moon Static*, *BEHEMOTH (slowed)*, *in the bleak midwinter (slowed)*. Обновлять: `python -m engine music radar`.

## 5. Уровень качества: что видно в 8 лучших роликах аккаунта

Разобраны ролики с 1.6M, 1.5M, 1.1M, 888K, 178K, 175K, 72K и 68K просмотров: бег по дорожкам, башни из блоков, падение и подъём, скалолазание, баскетбол, кафе, «5 минут сна», POV дисциплины.

| Приём | Как выглядит у них | Как сделано в движке |
|---|---|---|
| **Глянцевый пол** | Фигуры, блоки и свет отражаются в полу. Отражение мягкое и гаснет к низу кадра. | Слои фигур и эффектов зеркалятся относительно линии пола, проходят через маску затухания и лёгкий блюр (`reflect` у сцены; включено в `stage`, `arena`, `void`, `study`, `board`). |
| **Объёмные прожекторы** | Широкие мягкие лучи сверху, пятно света на полу, пылинки в луче. Когда персонаж сдаётся, его прожектор гаснет. | `props.spotlight` (кешированный луч + пятно + пыль), событие `spot` для яркости. |
| **Стройные фигуры с обводкой** | Голова меньше, конечности длинные, тонкая тёмная обводка у каждой части, видна граница рука/корпус. | `build: "slim"`, обводка всех частей в `rig.draw_figure`. |
| **Проигравшие гаснут** | Сдавшиеся становятся серыми, их ярлыки тускнеют. | Событие `dim`. |
| **Огонь мотивации** | У MOTIVATION на голове горит красный огонь, который гаснет. | `flame` у персонажа + событие `flame` (догорает в дым). |
| **Искорка таланта** | Маленькая звёздочка ✦ у головы TALENT. | Событие `sparkle`. |
| **Башни прогресса** | Белые светящиеся блоки складываются в башню, у готовой башни бьёт столб света. | Событие `stack` (поза «взял / положил» + счётчик блоков), эффект `light_pillar`. |
| **Ярлыки на полу** | Крупный моно-ярлык под фигурой. | `label_pos: "floor"` (по умолчанию в `stage`). |
| **Тонкие субтитры** | Сверху маленький моно-капс с большим трекингом: «POV : DISCIPLINE», «RESTER À TERRE EST UN CHOIX.». | Событие `text`, стиль `sub` по умолчанию. |
| **Плавность** | 60 fps, движение с весом. | `style.fps: 60`. |
| **Вотермарк** | Моно, мелко, около 82% высоты кадра. | `style.watermark`, `watermark_y`. |
