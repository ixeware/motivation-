# 3D-ролики (Blender + Mixamo)

Второй путь движка, для роликов в стиле настоящего 3D: белые toon-фигуры с чёрным контуром, мокап Mixamo,
прожекторы, чёрный зеркальный пол, пиксельный шрифт. Сцена собирается в Blender (как Python-модуль) и рендерится в Cycles на CPU.

## Установка
```bash
pip install bpy==5.2.3            # Blender как модуль, нужен Python 3.13
apt-get install -y ffmpeg
```

## Анимации Mixamo
У Mixamo нет публичного API. Клипы качаются через тот же API, что у сайта, с токеном **твоей** сессии
(в DevTools на mixamo.com: Console → `localStorage.access_token`). Токен живёт около суток.
Его не коммитят и не вставляют в чат: передают переменной окружения `MIXAMO_TOKEN` или файлом.
```bash
python -m engine mocap search "sitting"                 # каталог, без входа
python -m engine mocap fetch --token-file ~/.mixamo_token   # вся библиотека из engine/blender/mixamo.py
python -m engine mocap fetch "Sitting Yell|Sitting Forward" --token-file ~/.mixamo_token
python -m engine mocap list                              # что уже скачано
```
Клипы лежат в `assets/mocap/cache/` (в git не попадают: ассеты Mixamo нельзя распространять).
Без клипов можно ставить позы через IK (`kit.Rig`).

## Устройство
- `engine/blender/kit.py`: сцена и рендер (Cycles CPU), toon-материал и контур (inverted hull), капсулы,
  скелет X Bot → стикмен, IK с авто-калибровкой полюсов, прожекторы (без бликов в полу), камера, текст.
- `engine/blender/props.py`: стол, стул, ноутбук, телефон, отрывной календарь, окно, панель прогресса,
  бумага, стопки, стаканчики кофе, туча, дождь, молния.
- `engine/blender/mocap.py`: клипы Mixamo на фигуре, склейка через NLA с плавными переходами.
- `engine/blender/post.py`: свечения (телефон, экран, вспышки), bloom, манга-кадр, зерно, чёткий 2D-текст, ffmpeg.
- `engine/blender/films/<name>.py`: один модуль на ролик. `Film` строит сцену, `update(f)` выставляет кадр f
  (режиссёр), `glows(f)` отдаёт свечения для поста, `overlay_ops(f)` задаёт текст, `soundtrack()` собирает звук.
- `engine/blender/run.py`: рендер кадров (с докачкой после обрыва), пост, звук, `final.mp4`, `final_sfx_only.mp4`, обложка, подпись.

## Команды
```bash
python -m engine film procrastinator --preview --still 30,120,241   # контрольные кадры 360x640
python -m engine film procrastinator --preview                      # черновик целиком (~12 мин)
python -m engine film procrastinator                                # финал 1080x1920, 30 fps (~1.5–2 ч)
python -m engine film procrastinator --finish-only                  # только пост и звук по готовым кадрам
```
Кадры: `output/<slug>/frames/`. Если рендер прервался, повторный запуск продолжит с того же места.

## Правила стиля
- Камера фронтальная, чуть сверху. Ярлыки (`PROCRASTINATOR`, `PLANNER`) и титры рисуются в посте, а не в 3D.
- Пол чёрный, только отражения. У прожекторов `glossy=False`, иначе в полу видна полоса от края светового пятна.
- Один цветовой акцент на ролик: красный только в календаре, зелёный только у A+.
- Весь текст на английском, отсылки только визуальные (как и в 2D).
