# MOTIVATION ENGINE

Движок вертикальных мотивационных роликов в стиле «белые стикмены и ярлыки-архетипы» с фирменной атрибутикой и **скрытыми отсылками к аниме и фильмам**. По одному запросу собирает сценарий, синхронизирует кульминацию с дропом трека, рендерит 1080×1920 и отдаёт готовый mp4, обложку и подпись.

```bash
python -m engine make "талант и хардворк борются, а эго как годжо создаёт пурпурный и стреляет в них"
```

## Как пользоваться

### Вариант 1. Через Claude Code (рекомендую)
Напиши в чат одну фразу, например: *«сделай ролик: страх бьёт снова и снова, но колесо адаптации поворачивается»*.
Claude по скиллу `.claude/skills/make-video` соберёт черновик, доведёт сценарий под твою постановку, проверит кадры, отрендерит и пришлёт `final.mp4`, обложку и подпись.

### Вариант 2. Командой
```bash
python -m engine make "эго против таланта в классе, отсылка на расширение территории"      # сразу видео
python -m engine make "..." --plan-only            # только сценарий (scenarios/<slug>.json), чтобы поправить
python -m engine make "..." --music-url <tiktok>   # со звуком из конкретного TikTok
python -m engine render scenarios/<slug>.json      # рендер сценария
python -m engine render scenarios/<slug>.json --preview   # быстрый черновик в половинном разрешении
python -m engine still scenarios/<slug>.json 10.2  # один кадр в png
```
`make` берёт бриф у Claude API, если есть ключ (`ANTHROPIC_API_KEY` или `ant auth login`). Без ключа работает офлайн-планировщик по ключевым словам.
Запрос можно писать по-русски, **весь текст в видео будет на английском** (ярлыки, субтитры, финальная карточка). Подпись к посту тоже английская.

### Что получаешь (`output/<slug>/`)
- `final.mp4`: ролик с музыкой и SFX.
- `final_sfx_only.mp4`: только SFX. Его загружаешь в TikTok и в редакторе ставишь трендовый звук: так ролик попадает на страницу звука и его не глушат за копирайт.
- `cover.png`: кадр кульминации, его можно прогнать через GPT Image.
- `contact_sheet.jpg`: раскадровка для быстрой проверки.
- `caption.txt`: подпись, хэштеги, какой звук ставить и с какой секунды.

## Подбор музыки из TikTok

| Команда | Что делает | Нужны ключи? |
|---|---|---|
| `python -m engine music radar` | Сканирует последние ролики конкурентов из `config/competitors.txt`, группирует по звуку и ранжирует по просмотрам и свежести: что сейчас работает в нише. | нет |
| `python -m engine music fetch <url>` | Скачивает звук любого TikTok-ролика в `assets/music/tiktok/`. | нет |
| `python -m engine music research motivation discipline` | Официальный TikTok Research API: ролики по хэштегам за N дней → топ `music_id`. | `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` |
| `python -m engine music analyze <file>` | Темп, биты и дроп трека. | нет |

При рендере с треком движок сам находит дроп и сдвигает старт трека так, чтобы удар пришёлся ровно на дроп. Склейки подтягиваются к долям. Без трека играет процедурная подложка ~100 BPM с дропом на кульминации: её можно публиковать без проблем с правами.

## Шаблоны (выбираются по запросу)

| Шаблон | Сюжет | Отсылка по умолчанию |
|---|---|---|
| `classroom_rematch` | формат референса: оценки → провал → ночной грайнд → реванш | расширение территории |
| `duel_power` | двое дерутся → знамение → раскрытие героя → удар силы | пурпурная сфера |
| `grind_levelup` | окно квеста → учёба → тренировка → LEVEL UP + армия теней | окно системы |
| `adaptation` | героя бьют, колесо над головой поворачивается → адаптация → контрудар | колесо |
| `towers` | чёрная сцена, прожекторы, зеркальный пол: трое строят башни, двое сдаются, герой продолжает → столб света | армия теней + окно LEVEL UP |
| `exam_breakthrough` | гонка на экзамене: герой заглядывает в чужие листы → F → завязывает глаза → учится вслепую → на пересдаче стреляет пурпурным прямо в камеру → камера вылетает сквозь круглую дыру через всю школу | пурпурная сфера в экран + повязка |

## Устройство
```
engine/
  render/   rig.py (фигуры chunky/slim, 44 позы) · scenes.py (9 сцен, вкл. перспективный туннель) · vfx.py (15 эффектов) · renderer.py (камера, глубина резкости, зеркальный пол, пост)
  templates/ готовые выверенные сценарии-шаблоны (exam_breakthrough)
  audio/    sfx.py (процедурные звуки) · bed.py (подложка) · mix.py (биты, дроп, микс)
  music/    tiktok.py (радар, загрузка, Research API, локальная библиотека)
  blender/  kit.py · props.py · mocap.py (Mixamo) · post.py · run.py · films/ (по модулю на 3D-ролик)
  planner.py · references.py · pipeline.py · cli.py
```
Скорость: около 0.4–0.6 с на кадр 1080p на 4 ядрах. Ролик в 20 сек при 30 fps рендерится примерно за 4 минуты, при 60 fps — примерно за 10–15.
